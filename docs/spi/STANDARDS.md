# Engineering standards and codes applied (and where they show up)

Rule: name a standard only for what it really covers. Never quote a clause number you have not checked; write "per <standard>" and put the table or rule in `STANDARDS_APPLIED` in the app. Mark anything that is our policy choice, not the standard's text, as "Policy".

| Area | Standard | Use in this product |
|---|---|---|
| Asset and spares management | ISO 55000 / 55001 (asset management), ISO 14224 (collection and exchange of reliability and maintenance data) | Failure and maintenance data taxonomy for equipment classes and failure modes; the Data page maps our tables to ISO 14224 concepts (equipment class, failure mode, maintenance event). Governance and roadmap wording. |
| Criticality | Plant criticality S, A, B, C from the FuncLoc list (given). RCM method SAE JA1011 and API 580 risk-based thinking as the reasoning basis | Service-level policy table by criticality (Policy). Insurance-spare logic for S and A with no demand. API 580/581 cited for risk = probability x consequence in the stockout exposure. |
| Pumps and seals | API 610 / ISO 13709 (centrifugal pumps), API 682 / ISO 21049 (shaft sealing systems) | Equipment class names, parts-to-zone map for pump drawings (impeller, wear ring, sleeve, bearing, coupling, seal), spare-part families, typical spare sets. |
| Compressors and turbines | API 617 (axial and centrifugal compressors), API 612 (special-purpose steam turbines), API 614 (lubrication) | KC and KT set drawings and parts zones (journal and thrust bearings, labyrinth seals, rotor blades, governor valve), OEM-specific parts flagged as non-interchangeable. |
| Heat exchangers and furnaces | TEMA, API 660 / ISO 16812 (shell and tube), API 560 (fired heaters) | HE and BF set drawings, parts zones (tube bundle, gaskets, refractory castable for furnaces), turnaround-driven demand. |
| Valves and instruments | API 600 / 602 / 608 / 6D (valves), API 598 (valve testing), API 526 and 520 (pressure relief), ISA-5.1 (instrument identification and symbols), IEC 61511 / ISA-84 (functional safety), IEC 61508 | Part families for valves (trim set, seat ring, positioner, actuator diaphragm), instrument symbols and tag format on generated P&IDs (ISA-5.1), SIS and relief valves flagged as safety-critical spares, never recommended for disposal without review. |
| Piping and fasteners | ASME B31.3 (process piping), B16.5 (flanges), B16.9 and B16.11 (fittings), B16.20 (ring-joint and spiral-wound gaskets), B16.21 (non-metallic flat gaskets), B36.10M and B36.19M (pipe dimensions), ASTM A105, A234 WPB, A216 WCB, A106, A193 and A194 (bolting) | The ETL parses descriptions into item type, NPS, class (150#, 300#, 600#), grade, end connection (RF, SW, BW), schedule. Spec families group parts that are interchangeable by spec; family pooling uses them (better forecasts for sparse items) and the duplicate and substitution report uses them. |
| Vibration and condition | ISO 20816 (vibration of rotating machinery), ISO 13374 (condition monitoring data) | Mentioned as future condition-based demand input in the roadmap, not computed (no such data). |
| Inventory theory | Croston 1972, Syntetos and Boylan 2005 (SBA and classification cut-offs 1.32 and 0.49), Teunter, Syntetos and Babai 2011 (TSB), EOQ and newsvendor critical-ratio | Engine methods. Cited in the app's Method page and the deck appendix. |
| Documents | ASME Y14.100 and ISO 128 drawing conventions; plant tag numbering as in the FuncLoc list | Generated drawings carry a title block, a revision, and the note "Schematic generated from the baseline data, not a vendor drawing". |

Policy choices (ours, editable, labelled): service level by criticality, holding rate 22%, ordering cost per PO, downtime cost per day by criticality, insurance-spare rule (no demand, S or A, lead time above 90 days), slow-moving threshold (months of cover above 24).
